# 📊 Matplotlib Fundamentals & Data Visualization

This repository contains my practice scripts, core concepts, and visual data implementations using **Matplotlib**—the foundational plotting library for data visualization in Python.

---

## 📌 Topics Covered

* **Basic Plots:** Creating 1D and 2D charts using `plt.plot()`, `plt.scatter()`, `plt.bar()`, `plt.barh()`, and `plt.pie()`.
* **Statistical Visualizations:** Understanding distributions and data spread using `plt.hist()`, `plt.boxplot()`, and `plt.violinplot()`.
* **Customization & Aesthetics:** Adjusting plot colors, markers, line styles (`linestyle`), gridlines (`plt.grid()`), and legend positions (`plt.legend()`).
* **Subplots & Layouts:** Designing multi-plot layouts using `plt.subplots()`, `plt.subplot()`, and adjusting spacing with `plt.tight_layout()`.
* **Plot Exporting & Saving:** Saving high-resolution chart images using `plt.savefig()` in formats like `.png` and `.pdf`.

---

## 🛠 Tech Stack & Requirements

* **Language:** Python 3.x
* **Primary Package:** Matplotlib
